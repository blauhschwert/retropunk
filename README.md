# 🤖 Rogue Droid: Neon Rebellion

A retro-punk 2D action game inspired by late 80s / early 90s arcade chaos.  
Neon lights, broken circuits, and one machine that refuses to obey.

You play a **rogue droid** fighting through a decaying cyberpunk city ruled by gangs, megacorps, and corrupted systems.

---

## 🎮 About the Game

Built to serve.  
Glitched to rebel.

**Rogue Droid: Neon Rebellion** throws you into a gritty pixel-art future where analog tech, CRT screens, and synth noise define the atmosphere. Fast combat, unforgiving enemies, and pure arcade energy.

This project is developed with **Godot** and focuses on raw gameplay, style, and punk attitude over polish.

---

## ✨ Features

- 🕹️ Fast-paced 2D action gameplay  
- 🤖 Play as a rogue droid with illegal upgrades  
- 🎸 Retro-punk / cyberpunk atmosphere  
- 🎨 Pixel art inspired by 80s–90s arcade games  
- 📼 Old-school visual effects (CRT, scanl
